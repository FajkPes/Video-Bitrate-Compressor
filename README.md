# Video Bitrate Compressor

A Windows batch compressor that reduces each video's bitrate relative to its original bitrate.

## Key features

- Queue files and adjust video and audio settings.
- Use NVIDIA encoding when available or encode on the CPU.
- Check completed outputs before replacing the final file.

## Get started

Download the Windows ZIP from Releases and run `VideoBitrateCompressor.exe`.
